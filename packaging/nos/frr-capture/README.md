# Local FRR capture image

Build explicitly with `podman build -t localhost/netgeo/frr-capture:10.7.0 -f packaging/nos/frr-capture/Containerfile packaging/nos/frr-capture` from the repository root. NetGeo uses this image only when it already exists locally; otherwise emulated capture reports unsupported. The image is not bundled or published.

Base: `quay.io/frrouting/frr:10.7.0`, pinned registry manifest digest `sha256:65e5967b922572c0565d968388fb06af69d7e9b3b3eea40ad7e3810687667f68` (checked against `skopeo inspect --raw ... | sha256sum` on 2026-10-06). The local x86_64 build used Alpine 3.22.5, FRR `10.7.0_git-r0`, tcpdump `4.99.5-r1`, and libpcap `1.10.7-r0`; package versions and full SBOM vary with the Alpine repository at build time. FRR is generally GPL-2.0-or-later; [tcpdump](https://github.com/the-tcpdump-group/tcpdump/blob/master/LICENSE) and [libpcap](https://github.com/the-tcpdump-group/libpcap/blob/master/LICENSE) carry their own licenses. Consult upstream notices before distribution. This recipe is for local validation only; publication requires a versioned package manifest, SBOM, complete notices, and GPL corresponding-source review.
