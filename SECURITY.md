# Security Policy

## Versi yang didukung

Hanya `main` (rilis terbaru) yang didukung. Tidak ada backport ke tag lama —
proyek ini punya satu maintainer, jadi jalur tercepat untuk perbaikan adalah
update ke commit/tag terbaru.

## Melaporkan kerentanan

**Jangan buka issue publik untuk kerentanan keamanan nyata** — itu memberi
tahu penyerang sebelum ada perbaikan.

Laporkan lewat GitHub [private vulnerability reporting](https://github.com/NetGeo-Network-Simmulation/netgeo/security/advisories/new)
(tab **Security** di repo → **Report a vulnerability**). Sertakan langkah
reproduksi dan dampak yang kamu perkirakan.

## Ekspektasi respons

Ini proyek maintainer-tunggal (bukan tim korporat), jadi tidak ada SLA
formal. Realistisnya: acknowledgment dalam beberapa hari, perbaikan
tergantung tingkat keparahan dan waktu luang maintainer. Kalau tidak ada
respons dalam 2 minggu, boleh follow-up lewat issue biasa tanpa detail
sensitif ("saya lapor advisory tanggal X, belum ada respons").
