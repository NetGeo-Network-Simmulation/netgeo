# Security Policy

## Supported versions

Only `main` (the latest release) is supported. There's no backporting to
old tags — this project has a single maintainer, so the fastest path to a
fix is updating to the latest commit/tag.

## Reporting a vulnerability

**Don't open a public issue for a real security vulnerability** — that
tips off an attacker before a fix exists.

Report it via GitHub [private vulnerability reporting](https://github.com/NetGeo-Network-Simmulation/netgeo/security/advisories/new)
(the **Security** tab on the repo → **Report a vulnerability**). Include
reproduction steps and the impact you expect.

## Response expectations

This is a single-maintainer project (not a corporate team), so there's no
formal SLA. Realistically: acknowledgment within a few days, a fix
depending on severity and the maintainer's available time. If there's no
response within 2 weeks, feel free to follow up via a regular issue without
sensitive details ("I filed advisory on date X, no response yet").
